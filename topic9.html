Topic 9: Core HTML Attributes (href, src, alt, style)

Attributes provide vital additional information about elements and are always specified in the start tag.

  • href Attribute: Used inside the anchor element <a> to specify the destination URL or path of the linked page.
  • src Attribute: Used inside the image element <img> to define the exact image source path (absolute or relative URL).
  • alt Attribute: Specifies alternate fallback text if the image cannot load, which is crucial for screen readers and accessibility.
  • style Attribute: Used to define and apply presentation inline styling rules (color, font, layout) directly within a single element.
