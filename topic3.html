Topic 3: Understanding Uniform Resource Locator (URL) Anatomy

An anatomy breakdown of a standard URL structure (Example: https://www.itmbu.ac.in):

  • 1. Scheme / Protocol (https://): Hypertext Transfer Protocol Secure. Defines the protocol used to transmit data between your browser and the server. The "s" indicates an encrypted SSL/TLS connection protecting user data.
  • 2. Subdomain (www): World Wide Web subdivision of the main domain name that traditionally designates the primary web server hosting public pages.
  • 3. Second-Level Domain (itmbu): Organization Identifier representing the unique name chosen to distinguish its brand or identity on the internet.
  • 4. Top-Level Domain (.ac.in): Compound TLD Structure where .ac (Academic) is reserved for academic/educational institutions in India and .in is the Country Code TLD (ccTLD) designated for India.
