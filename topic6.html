Topic 6: Dynamic IP Address & Dynamic DNS (DDNS) Resolution

  • The Problem (Resolution Failure): Standard DNS A-records require static IP mapping. When a home or small business server's Dynamic IP changes dynamically upon router reboot or lease expiration, the domain lookup immediately fails.
  • The Solution (Dynamic DNS - DDNS): A lightweight daemon runs on the server. Whenever the WAN IP changes, it sends an authenticated API request to update the DNS A-record dynamically within seconds.
