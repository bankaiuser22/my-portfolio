Topic 4: URI vs. URL (The Umbrella Concept)

  • 1. URI (Uniform Resource Identifier): An overarching umbrella term for characters used to identify a resource on the internet. It gives a unique identity without necessarily showing how to access it. It features two main sub-categories: URLs (identifies by location) and URNs (identifies by unique name).
  • 2. URL (Uniform Resource Locator): A specific type of URI that not only identifies the resource but provides explicit instructions on how to locate and access it by including a protocol.

The Real-World Analogy: Think of a URI as a person's identity ("John Doe"), and a URL as their home address ("123 Main Street, Vadodara, Gujarat").
