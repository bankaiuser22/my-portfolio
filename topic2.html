Topic 2: Internet Infrastructure vs. WWW Architecture

Key Takeaway for CSE Engineers: The Internet provides the infrastructure (roads), while the WWW provides the service (vehicles and traffic running on the roads).

  • The Internet (Hardware/Network Layer): A globally decentralized network of networks (autonomous systems) operating on TCP/IP. Handles physical routers, fiber optics, packet switching, IP routing, and low-level transport protocols (TCP/UDP).
  • World Wide Web (Application/Data Layer): An information system running on top of the Internet. Invented by Sir Tim Berners-Lee at CERN (1989). Utilizes Hypertext, Uniform Resource Identifiers (URIs), and HTTP to interlink web documents worldwide.
