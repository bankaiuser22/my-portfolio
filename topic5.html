Topic 5: Web Browsers vs. Web Servers Core Architectures

  • Web Browser (User Agent Engine): Core objective is to fetch remote web assets, parse code, construct DOM/CSSOM trees, render layout, and execute client scripts. Key internal components include Rendering Engines (Blink, Gecko, WebKit) and JavaScript Engines (V8, SpiderMonkey).
  • Web Server (Server Daemon): Core objective is to listen on network sockets (0.0.0.0:80/443), accept HTTP requests, evaluate access controls, serve static files, or route to application runtimes. Uses asynchronous event-driven models (Nginx/Node.js) or process/thread per connection models (Apache).
