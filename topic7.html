Topic 7: Deep-Dive Analysis: IPv4 vs. IPv6 Comparison

  • Address Size: IPv4 uses a 32-bit IP address, whereas IPv6 uses a 128-bit IP address.
  • Notation: IPv4 uses decimal dot-separated notation (e.g., 66.94.29.13), while IPv6 uses alphanumeric hexadecimal colon-separated notation (e.g., 2001:db8::1).
  • IPsec Security: Optional in IPv4, but natively built directly into the protocol design for IPv6.
  • Header Size & Checksum: IPv4 has a variable header size (20–60 bytes) and includes a header checksum. IPv6 has a fixed header size of 40 bytes and does not include a header checksum field.
  • Transmission: IPv4 supports broadcast communication, whereas IPv6 uses multicast and anycast instead.
